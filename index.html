    About Me


    I'm a backend software engineer focused on building, designing, and shipping production systems across APIs, microservices, data-intensive applications, and cloud infrastructure. I work with FastAPI, Django, and Django REST Framework to build scalable backend services, alongside React-based frontends, asynchronous workflows, and AWS deployments. I'm also exploring AI application engineering, integrating large language models, Retrieval-Augmented Generation (RAG), semantic search, and tool calling into backend applications.

Beyond traditional backend development, I'm interested in building practical AI-powered features that combine document retrieval, structured application data, and LLMs. I also design and ship end-to-end systems, including multi-tenant SaaS platforms with their own backend architecture, infrastructure, and deployment pipelines.

    NoteStudio | Personal

    This is a full-stack note-taking application built using Django (DRF) for the backend and ReactJS for the frontend. It features secure authentication using JWT with registration, login, logout, token management, automatic token refresh, and blacklist handling for enhanced security.

    Users can seamlessly perform full CRUD operations on notes including create, edit, delete, pin, and unpin.

    A key feature of the platform is the ability to generate public shareable links for notes. Users can mark a note as public, which generates a unique link that can be shared on social media or with anyone. Recipients can view the note through the public archive page without needing an account. Notes can also be switched back to private at any time for full control over visibility.

    Deployment is automated using GitHub Actions CI/CD. The backend runs on AWS EC2 using Gunicorn and Nginx, with DuckDNS for domain routing and Let's Encrypt for HTTPS security. The frontend is hosted on Netlify, and the database is managed on NeonDB for reliability and performance.
